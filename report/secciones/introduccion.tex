\section{Introducción}

En el presente documento se verá el problema computacional de clase NP-completo llamado Clique Cover, para ello se presentará el problema en sí con su explicación, seguido de su modelo matemático, luego se explicará su razón de ser de la clase NP-completo con su NP-completitud y su relación con otros problemas.

\vspace{0.5 cm}

Posterior a eso se experimentará con este problema mediante dos soluciones, una base y otra mejorada, y cada una de estas ejecutadas en 3 lenguajes de programación, los cuales serán Java, Python y C++.

\vspace{0.5 cm}

Una vez obtenidos los resultados se analizarán sus tiempos de ejecución y comportamiento, esto para ver las diferencias de enfoque entre cada lenguaje con cada solución para relacionarlos a la complejidad del problema y determinar las ventajas y complicaciones de cada lenguaje y solución.
